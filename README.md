# Project overview
![Banner](./Banner.jfif)
This is a secured Express server setup. It contains a lot of feature such as:
- ✅Centralized error handling
- ✅ Custom AppError
- ✅ Async error handling
- ✅ Security headers with Helmet
- ✅ CORS
- ✅ Rate limiting
- ✅ Environment variables
- ✅ JSON/body limits
- ✅ 404 handling
- ✅ Graceful shutdown
- ✅ Clean project structure

As you can see if you're looking forward to build a node.js , or MERN stack, or PERN stack app. THIS IS A GREAT STARTING POINT

---

# How to get started using it

1. clone this repo
```bash
git clone 
```
2. install dependencies
```bash
npm install
```
3. Setup your .env file
4. Setup your routes and start developing
5. Start the server
```bash
npm run dev
```
